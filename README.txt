In this directory:
- Code: 
    - LangmuirExcitation.jl for evaluation
    - plotting_LE for visualization
- AlfvenTrainPSD/PSD/psd/: 
    - Etiennes PSD files
- AlfvenTrainPSD/PSD/psd/LE: 
    - Langmuir Excitation evaluated files. Same structure as Etiennes files, with additional fields. Evaluated for 3 different background electron densities.
- analyzed_parameters/:
    Guisdap files for background electron density
